# Learning plan compact placeholders

Placeholder ในช่องตารางแคบใช้ชื่อย่อเพื่อไม่ให้แถวขยายและหน้ากระดาษเลื่อน ชื่อย่อสำคัญมีดังนี้:

- `uc_*`: ตารางหน่วยสมรรถนะ
- `eoc_*`: สมรรถนะย่อย
- `a_*`: ตารางวิเคราะห์หลักสูตร
- `s_*`: ตารางกำหนดการสอน
- `e_*`: ตารางประเมินสมรรถนะ
- `course`, `course_code`, `course_label`: ชื่อ รหัส และข้อความรวมของรายวิชา
- `teacher`, `dept_head`, `director`: ผู้สอน หัวหน้าสาขา และรองผู้อำนวยการ
- `*_sign`: ลายเซ็น
- `*_date`: วันที่

ชื่อเต็มอื่นที่อยู่ในช่องเนื้อหาขนาดใหญ่ยังคงใช้ชื่อเดิม เพื่อให้ความหมายชัดเจนและไม่กระทบการจัดหน้า
